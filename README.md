# Small Business Website Launch Checklist

A practical checklist for small business owners, web developers, and website managers. Use it to review essential website features before launch and identify tasks that need attention.

## 1. Mobile Usability

- [ ] Check the website on mobile, tablet, and desktop.
- [ ] Test navigation menus and buttons.
- [ ] Check that text is readable on smaller screens.
- [ ] Make sure important content fits the screen properly.

## 2. Contact Forms and Business Information

- [ ] Submit a test through each contact form.
- [ ] Confirm that form submissions reach the correct inbox.
- [ ] Test phone number and email links.
- [ ] Verify the business name, address, phone number, and opening hours.
- [ ] Check that form errors are clear and understandable.

## 3. Security and Backups

- [ ] Confirm that the website uses HTTPS.
- [ ] Check that a recent backup is available.
- [ ] Review administrator accounts and permissions.
- [ ] Update website software and plugins safely.
- [ ] Confirm that the backup restoration process is documented.

## 4. Technical SEO

- [ ] Give important pages clear, descriptive title tags.
- [ ] Write useful meta descriptions where appropriate.
- [ ] Check that important pages can be indexed.
- [ ] Review the XML sitemap.
- [ ] Test internal links and important redirects.
- [ ] Check for accidental `noindex` directives.
- [ ] Confirm that canonical URLs are configured correctly where needed.

## 5. Performance and Accessibility

- [ ] Optimize images without noticeably reducing quality.
- [ ] Test performance with [PageSpeed Insights](https://pagespeed.web.dev/).
- [ ] Check keyboard navigation and visible focus indicators.
- [ ] Add appropriate alternative text to informative images.
- [ ] Ensure form fields have clear labels.
- [ ] Check text contrast and heading structure.

## 6. Analytics and Final Review

- [ ] Configure analytics if required.
- [ ] Test important actions, such as form submissions and phone calls.
- [ ] Check for broken links and missing pages.
- [ ] Review important pages for outdated information.
- [ ] Assign responsibility for ongoing website maintenance.

## How to Use This Checklist

Review each item and mark it when it has been checked. Record any problems separately and prioritize issues that affect security, accessibility, usability, or essential business functions.

Not every item applies to every website. Adapt the checklist to the website's platform, features, and business requirements.

This checklist supports a basic review but does not replace a professional security audit, comprehensive accessibility evaluation, or technical SEO audit.
